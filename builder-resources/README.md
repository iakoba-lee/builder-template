# Builder Resources

Curated reading, courses, and accounts for becoming an AI product builder, organized by the
six Builder axes tracked in `sprints/` (see `.claude/skills/sprint-review`). Source:
[BYU Strategy — Builder Resources](https://byu-strategy.github.io/product-management/97-builder-resources.html),
verified August 2026.

**How to use this.** Don't work through it top to bottom. Find your lowest axis on your
baseline profile (`sprints/baseline-chart.png`), start with the item marked *Start here* in
that axis's file, and come back for the rest when you need it.

Each file below has the resource table for that axis plus a ready-to-paste tutor prompt for
Claude Code — it reads the sources itself, finds out what you already know, and teaches
against your own project instead of a tutorial app.

- [Discovery](discovery.md) — what to build, and for whom
- [Design](design.md) — the surface and the flow
- [Application Architecture](application-architecture.md) — how the app is structured, shipped, and kept safe
- [AI Systems](ai-systems.md) — the intelligence inside the product
- [Agentic Workflow](agentic-workflow.md) — AI as the way you build
- [Launch and Learn](launch-and-learn.md) — getting it in front of people and finding out whether it worked

Anthropic moved several documentation URLs during 2025 and 2026, so older links found
elsewhere may redirect or break.
